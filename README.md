# 📱 图片浏览器 - GitHub Actions 自动构建

## 使用步骤（手机操作即可）

### 第一步：创建 GitHub 仓库
1. 打开 [github.com](https://github.com) 并登录
2. 点击右上角 **"+"** → **"New repository"**
3. 仓库名填：`image-browser`
4. 选择 **Public**（公开）
5. 勾选 **"Add a README file"**
6. 点击 **"Create repository"**

### 第二步：上传文件
进入仓库后，按顺序上传本压缩包中的所有文件，**保持目录结构不变**。

> 💡 手机上传技巧：点击仓库页面的 **"Add file"** → **"Upload files"**，一次可以多选上传。

### 第三步：等待自动构建
上传完成后，点击仓库顶部的 **"Actions"** 标签页，可以看到构建进度（约 5-10 分钟）。

### 第四步：下载 APK
构建完成后：
1. 点击 **Actions** → 选择最新的构建记录
2. 滚动到页面底部 **"Artifacts"** 区域
3. 点击 **"image-browser-debug-apk"** 即可下载！

---

## 注意事项
- 下载的是 zip 压缩包，解压后得到 `app-debug.apk`
- 安装前需在手机设置中开启"允许安装未知来源应用"
- APK 文件有效期 90 天
